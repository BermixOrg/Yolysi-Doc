# Troubleshooting

## Generation

| Message or symptom | Cause | Fix |
|---|---|---|
| *Brand Kit not found — set one up before generating* | No active Brand Kit | [Create a Brand Kit](../brand-kit/creer-son-brand-kit.md) |
| *Insufficient balance* / *Insufficient credits* | Not enough points | [Understanding points](../credits-et-facturation/comprendre-les-points.md), [change plan](../credits-et-facturation/changer-de-plan.md) |
| *Could not create the generation job — try again* | Temporary error | Retry in a moment |
| *Select an article before generating* | No opportunity chosen | Pick one in the SERP analysis window |
| *Enter a topic to generate the content* | Empty evergreen topic | Fill in the **Authority topic** field |
| No relevant idea | Keywords too narrow | Broaden the Brand Kit pillar keywords |

## Publishing

| Message or symptom | Fix |
|---|---|
| *Session expired, please reload the page* | Reopen Yolysi from the Shopify admin |
| *Unable to fetch blogs* | Create a blog in Shopify, then retry |
| *This content is already published* | Published content can't be published again |
| Image not processed in time | Retry the publication |

## Monitoring

| Symptom | Fix |
|---|---|
| *No published content* | Publish content first |
| No data | Connect Search Console ([guide](../monitoring/connecter-google.md)) and use a longer period |
| *Reconnect required* (Google Ads) | **Reconnect Google** in Setup |
| Core Web Vitals missing | The measurement arrives on the next analysis; otherwise [contact support](support.md) |
| Backlink data unavailable | Try again later |

## Nothing works?

Reload the app from Shopify. If the problem persists, open a **Bug** ticket in [support](support.md) with the page, the exact message and the time.
