# Glossary

| Term | Definition |
|---|---|
| **AEO** | *Answer Engine Optimization*: optimizing content so it's picked up in AI assistants' and answer engines' replies. |
| **GEO** | *Generative Engine Optimization*: a close relative of AEO, focused on generative engines. |
| **AI Overview** | AI-generated answer box at the top of some Google results pages. |
| **Backlink** | A link from another site to yours. |
| **Brand Kit** | Brand identity (tone, persona, keywords, rules) applied to every generation. |
| **Draft** | Generated content not yet sent to Shopify. |
| **Canonical** | A page's reference URL, when several addresses show similar content. |
| **Core Web Vitals** | Real-world page performance measures (speed, stability, responsiveness). |
| **CTR** | *Click-Through Rate*: share of people who click after seeing your link. |
| **CTA** | *Call to action*: a button or block that invites action (e.g. view the product). |
| **Referring domain** | A distinct site containing at least one link to yours. |
| **Evergreen** | Timeless content that stays relevant for years. |
| **Featured snippet** | Answer highlighted above the results. |
| **GA4** | Google Analytics 4, audience measurement tool. |
| **GSC** | Google Search Console, source of clicks, impressions and positions. |
| **Internal linking** | Links between your own pages. |
| **MCP** | *Model Context Protocol*: a standard that lets an AI assistant use external tools such as Yolysi. |
| **People Also Ask** | Related questions shown by Google, the basis of answer blocks. |
| **Persona** | Portrait of the target reader. |
| **Point / credit** | Yolysi's unit of consumption. |
| **Quality Score** | A 1–10 rating assigned by Google Ads to a keyword. |
| **Impression share** | Share of possible impressions your ad actually received. |
| **SEO** | *Search Engine Optimization*: organic search ranking. |
| **SERP** | *Search Engine Results Page*. |
| **Rich result** | Google result with extra elements (rating, FAQ, price…). |
