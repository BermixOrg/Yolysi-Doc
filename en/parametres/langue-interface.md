# Interface language and content language

Yolysi handles **two independent languages**.

| Setting | Where | What it changes |
|---|---|---|
| **Interface language** | **Settings → Organization** | The language of the app's menus, buttons and messages. Available: French, English. |
| **Content language** | **Brand Kit → SEO & Market** (and the generation form) | The language in which the AI **writes** your articles, pages and product sheets. |

## Example

You can use the interface in **French** and generate content in **English** for an export market: just set the Brand Kit language to English.

## Change the interface language

1. **Settings → Organization → Interface language**.
2. Choose the language: it applies immediately and is remembered.

## Change the content language

See [Create your Brand Kit](../brand-kit/creer-son-brand-kit.md) and, at generation time, the **Content language** field (French, English, Spanish, German).

> The **SERP region** (which Google is analyzed) is a separate setting: it determines which competitors are analyzed, not the writing language.
