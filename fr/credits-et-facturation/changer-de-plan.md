# Changer de plan

## Principe

L'abonnement passe par la **facturation native de Shopify** : le plan appliqué dans Yolysi est toujours celui de l'abonnement Shopify actif.

## Étapes

1. Ouvrez **Facturation**.
2. Dans **Choisir un plan**, repérez votre plan (badge **Votre plan**) et cliquez sur **Commencer →** sur celui que vous voulez.
3. Vous êtes redirigé vers Shopify pour **approuver** l'abonnement.
4. De retour dans Yolysi, le message *Plan … activé avec succès* confirme le changement et vos points sont réinitialisés selon le nouveau plan.

## Annuler ou rétrograder

Si l'abonnement est **annulé, refusé, expiré ou gelé** côté Shopify, votre compte repasse automatiquement sur le plan **Gratuit**. Un paiement en attente (*pending*) ne change rien tant qu'il n'est pas approuvé.

## Ce qui se passe pour vos points

- Les points **mensuels** suivent le nouveau plan.
- Les **packs** restent valables tant que l'abonnement est actif ([détails](comprendre-les-points.md)).
- Les contenus déjà générés ne sont pas affectés.
