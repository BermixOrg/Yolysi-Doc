# Documentation Yolysi

Yolysi est une application Shopify qui **génère, publie et suit du contenu SEO et AEO** (optimisé pour les moteurs de recherche *et* pour les assistants IA comme ChatGPT, Gemini ou Claude), à partir de l'identité de votre marque.

> **Principe clé :** Yolysi ne publie jamais rien tout seul. Tout contenu généré arrive en **brouillon** et vous le relisez avant de l'envoyer sur votre boutique.
