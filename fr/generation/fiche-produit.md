# Fiche produit

## À quoi ça sert

Remplacer une description pauvre, copiée du fournisseur ou dupliquée par un texte centré sur les **bénéfices** et la **conversion**, dans le ton de votre marque.

## Prérequis

[Brand Kit actif](../brand-kit/creer-son-brand-kit.md) et au moins un produit dans votre boutique. Solde suffisant : coût **TBD**.

## Étapes

1. Choisissez **Fiche produit**.
2. Dans **Choisir un produit**, cherchez le produit (barre de recherche) ; **Charger plus de produits** affiche la suite du catalogue.
3. Sélectionnez-le. La génération démarre avec le coût indiqué.
4. Relisez le résultat dans vos [brouillons](../brouillons-et-publication/relire-et-modifier.md).

## ⚠️ Avant de publier

Contrairement aux articles et pages, qui sont créés non publiés, la publication d'une fiche produit **remplace directement la description du produit** dans votre boutique. Relisez avec soin, et conservez l'ancienne description si vous voulez pouvoir y revenir. Détails : [Publier sur Shopify](../brouillons-et-publication/publier-sur-shopify.md).

## Erreur fréquente

- **« Aucun produit trouvé dans cette boutique »** : vérifiez que le catalogue contient des produits et que l'application a bien accès aux produits.
