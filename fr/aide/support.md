# Contacter le support

## Ouvrir un ticket

1. Dans l'application, ouvrez **Support**.
2. Cliquez sur **Nouveau ticket**.
3. Renseignez :
   - **Sujet** *(obligatoire)* : votre problème en quelques mots ;
   - **Catégorie** : Général, Facturation, Bug, Fonctionnalité ou Contenu ;
   - **Priorité** : Bug bloquant, Bug non bloquant, Amélioration ou Info / Suggestion ;
   - **Message** *(obligatoire)* : décrivez le problème en détail.
4. Cliquez sur **Envoyer**.

![Fenêtre Nouveau ticket](../../images/aide/01-nouveau-ticket.png)

## Suivre un ticket

La liste affiche vos tickets, filtrables par **Ouvert**, **En cours**, **Résolu**, **Fermé**. Sélectionnez-en un pour lire l'échange avec l'équipe et répondre (Entrée pour envoyer). **Marquer comme résolu** clôt votre demande ; un ticket fermé ne peut plus recevoir de message : ouvrez-en un nouveau.

## Bien décrire un problème

- La page concernée et ce que vous vouliez faire.
- Le **message d'erreur exact**.
- L'heure approximative et le type de contenu.
- Ce que vous avez déjà essayé ([dépannage](depannage.md)).
