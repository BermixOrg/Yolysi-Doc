# Dépannage

## Génération

| Message ou symptôme | Cause | Solution |
|---|---|---|
| *Brand Kit introuvable — configurez-en un avant de générer* | Aucun Brand Kit actif | [Créer un Brand Kit](../brand-kit/creer-son-brand-kit.md) |
| *Solde insuffisant* / *Crédits insuffisants* | Pas assez de points | [Comprendre les points](../credits-et-facturation/comprendre-les-points.md), [changer de plan](../credits-et-facturation/changer-de-plan.md) |
| *Impossible de créer la tâche de génération — réessayez* | Erreur temporaire | Réessayez après quelques instants |
| *Sélectionnez un article avant de générer* | Aucune opportunité choisie | Choisissez-en une dans la fenêtre d'analyse SERP |
| *Saisissez un sujet pour générer le contenu* | Sujet evergreen vide | Remplissez le champ **Sujet d'autorité** |
| Aucune idée pertinente | Mots-clés trop étroits | Élargissez les mots-clés piliers du Brand Kit |

## Publication

| Message ou symptôme | Solution |
|---|---|
| *Session expirée, rechargez la page* | Rouvrez Yolysi depuis l'administration Shopify |
| *Impossible de récupérer les blogs* | Créez un blog dans Shopify, puis réessayez |
| *Ce contenu est déjà publié* | Un contenu publié ne peut pas être republié |
| Image non traitée à temps | Réessayez la publication |

## Monitoring

| Symptôme | Solution |
|---|---|
| *Aucun contenu publié* | Publiez d'abord un contenu |
| Aucune donnée | Connectez Search Console ([guide](../monitoring/connecter-google.md)) et allongez la période |
| *Reconnexion requise* (Google Ads) | **Reconnecter Google** dans Configuration |
| Core Web Vitals absents | La mesure arrive à la prochaine analyse ; sinon [contactez le support](support.md) |
| Données backlinks indisponibles | Réessayez plus tard |

## Rien ne fonctionne ?

Rechargez l'application depuis Shopify. Si le problème persiste, ouvrez un ticket **Bug** dans le [support](support.md) en précisant la page, le message exact et l'heure.
