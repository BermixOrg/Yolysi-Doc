# Glossaire

| Terme | Définition |
|---|---|
| **AEO** | *Answer Engine Optimization* : optimiser un contenu pour qu'il soit repris dans les réponses des assistants IA et moteurs de réponse. |
| **GEO** | *Generative Engine Optimization* : voisin de l'AEO, centré sur les moteurs génératifs. |
| **AI Overview** | Encart de réponse généré par l'IA en haut de certaines pages de résultats Google. |
| **Backlink** | Lien d'un autre site vers le vôtre. |
| **Brand Kit** | Identité de marque (ton, persona, mots-clés, règles) appliquée à chaque génération. |
| **Brouillon** | Contenu généré, pas encore envoyé à Shopify. |
| **Canonique** | URL de référence d'une page, quand plusieurs adresses affichent un contenu proche. |
| **Core Web Vitals** | Mesures de performance réelle d'une page (vitesse, stabilité, réactivité). |
| **CTR** | *Click-Through Rate* : part des personnes qui cliquent après avoir vu votre lien. |
| **CTA** | *Call to action* : bouton ou bloc qui invite à agir (ex. voir le produit). |
| **Domaine référent** | Site distinct qui contient au moins un lien vers le vôtre. |
| **Evergreen** | Contenu intemporel qui reste pertinent des années. |
| **Extrait optimisé** | *Featured snippet* : réponse mise en avant au-dessus des résultats. |
| **GA4** | Google Analytics 4, outil de mesure d'audience. |
| **GSC** | Google Search Console, source des clics, impressions et positions. |
| **Maillage interne** | Liens entre vos propres pages. |
| **MCP** | *Model Context Protocol* : standard qui permet à un assistant IA d'utiliser des outils externes comme Yolysi. |
| **People Also Ask** | Questions associées affichées par Google, base des blocs de réponse. |
| **Persona** | Portrait du lecteur cible. |
| **Point / crédit** | Unité de consommation de Yolysi. |
| **Quality Score** | Note de 1 à 10 attribuée par Google Ads à un mot-clé. |
| **Part d'impressions** | Proportion des affichages possibles que votre annonce a obtenus. |
| **SEO** | *Search Engine Optimization* : référencement naturel. |
| **SERP** | *Search Engine Results Page* : page de résultats d'un moteur de recherche. |
| **Résultat enrichi** | Résultat Google avec éléments en plus (note, FAQ, prix…). |
