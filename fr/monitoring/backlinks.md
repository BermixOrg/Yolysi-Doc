# Backlinks `BÊTA`

> Cette fonctionnalité est en **bêta**.

## À quoi ça sert

Un **backlink** est un lien d'un autre site vers le vôtre ; ils comptent pour le référencement. Cet onglet vous aide à comprendre votre profil et à repérer des sites qui lient vos concurrents mais pas vous.

> **Rien n'est envoyé automatiquement.** Yolysi ne contacte personne : c'est un outil de visibilité, vous décidez quoi faire de la liste.

## Prérequis

- Le domaine de votre site : déterminé via [Search Console](connecter-google.md) ; sans lui, un message vous invite à connecter Search Console.
- Un solde suffisant pour un audit : coût **TBD**.

## Étapes

1. **Monitoring → Backlinks**.
2. **Concurrents suivis** : ajoutez jusqu'à **5** domaines concurrents, à la main (**Ajouter**) ou via **Suggérer des concurrents** (comptez 20 à 25 secondes ; cliquez sur une suggestion pour l'ajouter). **Retirer** supprime un domaine.
3. Cliquez sur **Lancer l'audit**.

![Page Backlinks](../../images/monitoring/04-backlinks.png)

## Résultats

| Bloc | Contenu |
|---|---|
| **Profil de backlinks** | Domaine analysé, rang, nombre de backlinks, domaines référents, backlinks cassés, score de spam. |
| **Domaines à contacter (écart concurrents)** | Domaines qui lient un concurrent mais pas vous. |
| **Prospects prioritaires** | Parmi eux, ceux qui lient **au moins deux** de vos concurrents, classés par autorité. |

**Exporter en CSV** télécharge la liste des prospects.

## Limites

- Un audit ne peut être relancé qu'**après un délai** (message *Un audit a déjà été exécuté récemment — réessayez plus tard*).
- Le solde de points est vérifié avant l'audit ; il n'est débité qu'en cas de succès.
- Si les données sont indisponibles : *Backlinks indisponibles pour le moment*, réessayez plus tard.

## Historique

Chaque audit est conservé, ce qui permet de suivre l'évolution de votre profil dans le temps.
