# Installer l'application

## Prérequis

- Une boutique Shopify.
- Un compte ayant le droit d'installer des applications sur cette boutique.

## Étapes

1. Ouvrez la fiche de Yolysi sur le **Shopify App Store** et cliquez sur **Ajouter l'application**.
2. Shopify affiche les autorisations demandées. Lisez-les, puis validez l'installation.
3. Yolysi s'ouvre directement dans l'administration Shopify. **Aucune configuration manuelle** n'est nécessaire : votre espace est créé automatiquement.
4. Vous arrivez sur le [tableau de bord](tableau-de-bord.md). Passez ensuite aux [premiers pas](premiers-pas.md).

![Écran d'autorisation Shopify lors de l'installation](../../images/demarrage/01-installation-autorisations.png)

## Autorisations demandées

| Autorisation | Pourquoi |
|---|---|
| Lire les produits | Proposer vos produits dans les générations et alimenter le Brand Kit. |
| Écrire les produits | Mettre à jour la description d'un produit quand vous publiez une fiche produit. |
| Lire et écrire le contenu | Créer des articles de blog et des pages. |
| Écrire les fichiers | Envoyer les images générées vers les Fichiers de votre boutique. |

Yolysi **ne demande aucun accès aux clients ni aux commandes**.

## Votre plan de départ

Une nouvelle installation démarre sur le plan **Gratuit**. Quota de points : **TBD** (voir [plans](../credits-et-facturation/plans.md)).

## Désinstaller

La désinstallation se fait depuis l'administration Shopify. Vos données sont ensuite supprimées : voir [Confidentialité et données](../aide/confidentialite-donnees.md).
