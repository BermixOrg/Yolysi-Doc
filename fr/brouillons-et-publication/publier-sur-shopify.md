# Publier sur Shopify

## Prérequis

Un brouillon relu. Une fois publié, un contenu ne peut pas être republié (message *Ce contenu est déjà publié*).

## Étapes

1. Sur **Brouillons** ou sur la page du contenu, cliquez sur **Publier sur Shopify**.
2. Confirmez (*Confirmer la publication de ce contenu sur Shopify ?*).
3. Pour un **article de blog**, choisissez le **blog de destination** dans la fenêtre, puis **Publier sur ce blog**.
4. Attendez la fin (« Publication… »). Le contenu passe au statut **Publié**.

## Ce qui est créé selon le type

| Type de contenu | Ce qui se passe dans Shopify | Mise en ligne |
|---|---|---|
| **Article de blog** | Un article est créé dans le blog choisi, avec vous comme auteur. | **Non publié** : à activer dans Shopify. |
| **Evergreen** | Une page est créée. Des métachamps (scores SEO/AEO, type de schéma, nombre de mots…) sont ajoutés. Si la sortie est une image, elle est envoyée dans les Fichiers. | **Non publié** : à activer dans Shopify. |
| **Fiche produit** | La **description du produit existant est remplacée**. | ⚠️ **Immédiat** : la description du produit change tout de suite. |

> ⚠️ **Fiche produit :** aucune étape intermédiaire. Si le produit est en ligne, la nouvelle description l'est aussi. Relisez soigneusement avant de confirmer.

## Après la publication

- Pour un article ou une page, ouvrez Shopify et passez le contenu en **visible** quand vous êtes prêt.
- Le contenu publié rejoint le **maillage interne** : les prochains articles pourront pointer vers lui.
- Vous pouvez le [suivre dans le monitoring](../monitoring/vue-ensemble.md).

## Erreurs fréquentes

| Message | Cause / solution |
|---|---|
| *Session expirée, rechargez la page* | Rouvrez l'application depuis l'administration Shopify. |
| *Impossible de récupérer les blogs* | Votre boutique n'a peut-être aucun blog : créez-en un dans Shopify. |
| *Erreur lors de la publication* | Réessayez ; si cela persiste, contactez le [support](../aide/support.md). |
| L'image n'a pas été traitée à temps | Shopify traite les images avec un délai : réessayez la publication. |
