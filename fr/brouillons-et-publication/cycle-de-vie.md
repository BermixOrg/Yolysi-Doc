# Le cycle de vie d'un contenu

```
Génération (IA) → Brouillon → Relecture (vous) → Publication Shopify
```

## Les étapes

1. **Génération** : Yolysi produit le contenu à partir de votre [Brand Kit](../brand-kit/creer-son-brand-kit.md).
2. **Brouillon** : le contenu est enregistré et listé dans **Brouillons**. Il n'existe pas encore dans Shopify.
3. **Relecture** : vous lisez, corrigez, demandez une amélioration IA si besoin ([relire et modifier](relire-et-modifier.md)).
4. **Publication** : vous envoyez le contenu vers Shopify ([publier](publier-sur-shopify.md)). Articles et pages y arrivent **non publiés** ; vous gardez une dernière validation dans Shopify avant la mise en ligne.

## Statuts

| Statut | Signification |
|---|---|
| **Brouillon** | Généré, pas encore envoyé à Shopify. |
| **Publié** | Envoyé à Shopify. Peut alors être [suivi dans le monitoring](../monitoring/vue-ensemble.md). |
| **Archivé** | Mis de côté. |

## Versions

Quand vous améliorez un contenu avec l'IA, une **nouvelle version** est créée sans perdre les précédentes. Elles sont listées dans la section **Versions** de la page du contenu.

## Où retrouver vos contenus

- **Brouillons** : ce qui attend votre validation.
- [**Historique**](historique.md) : tous les contenus, tous statuts confondus.

> Yolysi ne publie **jamais** de lui-même. Aucune génération, aucune connexion IA ne contourne cette étape.
